# Contributing

This project is currently not accepting contributions.

SPLine Interatomic Cluster Expansion (SPLICE) accompanies a research paper. We
may publish updates, but there is no general contribution process and
unsolicited pull requests will not be reviewed.

Please feel free to contact the corresponding authors of the accompanying paper
if you would like to contribute. Where a contribution is agreed, we will make
arrangements for it at that point.

You are welcome to fork the repository and modify it under the terms of the
[Apache License 2.0](LICENSE).

To report a security vulnerability, please follow [SECURITY.md](SECURITY.md).
